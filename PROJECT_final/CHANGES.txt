AILAF - FINAL CODE UPDATE
=========================

HOW TO USE
1. Copy these files over your project folder (keep your data/oulad folder).
2. Optional but recommended: run  python preprocessing.py  then  python train_models.py
   (retrains the models with the libraries on your computer, about 2 to 3 minutes).
   Do this if you see an error loading the .joblib model files.
3. Run  streamlit run app.py        (student app)
   or   streamlit run app_ekb.py    (same app + EKB Management for lecturers)
